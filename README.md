# 決算集計

小口現金のExcelから、勘定科目別の集計・損益計算書・貸借対照表を作るツールです。

HTMLファイル1枚で動きます。インストールも会員登録も不要です。

---

## 何ができるか

1. **Excelを読む** — 月別シートをまとめて読み込みます
2. **点検** — 重複、期間外、マイナス金額、残高行などを自動で洗い出します
3. **費目を振り分ける** — 費目を勘定科目に対応づけます。決めた内容は記憶されます
4. **一件ずつ判断** — 内容によって扱いが変わる費目だけ、行ごとに決められます
5. **損益計算書** — 勘定科目別に集計して表示します
6. **貸借対照表** — 期首残高と当期の増減から作ります

## データはどこにも送信されません

Excelの中身はブラウザの中だけで処理されます。サーバーへの送信は一切ありません。

会社名・期首残高・費目の振り分けは、お使いのパソコンのブラウザ内（localStorage）にのみ保存されます。**このHTMLファイル自体には、会社の数字は一つも入っていません。**

保存内容は「0　会社の設定」の画面からいつでも消せます。

なお保存はパソコン単位・ブラウザ単位です。複数台でお使いの場合、それぞれで設定が必要になります。

## Excelの形式

シート名に「家計」を含むシートを読みます。列は**位置**で判定しますので、見出しの言葉は月ごとに違っていても構いません。

| 列 | 内容 |
|---|---|
| A | 日付 |
| B | 曜日（読みません） |
| C | 費目 |
| D | 収入 |
| E | 信用支出（カード等） |
| F | 現金支出 |
| G | 内容・摘要 |

A列が日付でない行は見出し・空行として自動で飛ばします。見出し行がなくても構いません。

## 使い方

1. `kessan.html` をブラウザで開く（ダブルクリックでも、公開URLからでも）
2. 「0　会社の設定」に会社名と会計期間を入れる
3. Excelを放り込む
4. 画面の順に進む
