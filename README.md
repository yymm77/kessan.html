# 決算集計

小口現金のExcelから、損益計算書・貸借対照表・申告書への転記表を作るツールです。

HTMLファイル1枚で動きます。インストールも会員登録も不要です。

> **開発中です。** 令和8年10月期の決算を実際に処理しながら作っています。まだ一度も本番の申告を通っていません。お使いになる場合は、必ずご自身で検算してください。

---

## 対象

**法人向けです。** 出力される決算書は法人の様式で、転記表は法人税申告書の別表を前提にしています。

個人事業主の方の場合、青色申告決算書は様式が異なり（元入金・事業主貸／事業主借など）、そのままでは提出できません。仕訳と集計の部分はお使いいただけますが、印刷される帳票は法人専用です。

小さな法人、とくに経理をご自身でされている一人法人を想定しています。

## できること

| 画面 | 内容 |
|---|---|
| 0　会社の設定 | 会社名・会計期間・期首残高・前期実績を一度だけ入力 |
| 1　Excelを読む | 月別シートをまとめて読み込む。複数ファイル可 |
| 2　点検 | 重複・期間外・マイナス金額・残高行を自動で洗い出す |
| 3　費目を振り分ける | 費目を勘定科目に対応づける。決めた内容は記憶される |
| 4　一件ずつ判断 | 内容によって扱いが変わるものを、まとめて判断する |
| 5　損益計算書 | 勘定科目別に集計。前期と並べて表示 |
| 6　貸借対照表 | 期首残高と当期の増減から作成。貸借の一致を検証 |
| 7　印刷する | 決算書一式・申告書への転記表・総勘定元帳・仕訳一覧 |
| ＋　領収書を取り込む | メール本文やPDFから日付・金額・支払先を読み取る |

### 一件ずつ判断について

同じ費目でも、内容によって会社の経費か私的なものかが分かれます。このツールは、内容の似たものをグループにまとめ、一度決めれば仲間すべてに適用します。

判断の候補（提案）は表示しますが、**利用者が確定ボタンを押すまで何も決まりません。** 10万円以上を含むグループは、一括確定の対象から外します。

期の途中で扱いが変わったものは、日付で前半・後半に分けて別々に決められます。

### 領収書の取り込み

メールの本文を貼り付けるか、PDFを放り込むと、日付・金額・支払先・費目・支払方法を読み取ります。読み取った内容は画面上で修正でき、Excelに貼り付けられる形で書き出せます。

**紙のレシートを撮影・スキャンしたPDFは読み取れません。** 文字が画像になっているためです。その場合はその旨を表示します。

## データはどこにも送信されません

Excelの中身も、領収書の内容も、ブラウザの中だけで処理されます。外部への通信は一切ありません。

会社名・期首残高・費目の振り分けは、お使いのパソコンのブラウザ内（localStorage）にのみ保存されます。**このHTMLファイル自体には、会社の数字は一つも入っていません。**

保存内容は「0　会社の設定」の画面からいつでも消せます。

なお保存はパソコン単位・ブラウザ単位です。複数台でお使いの場合、それぞれで設定が必要になります。バックアップも取られません。

## Excelの形式

シート名に**「家計」を含む**シートを読みます。列は**位置**で判定しますので、見出しの言葉は月ごとに違っていても構いません。

| 列 | 内容 |
|---|---|
| A | 日付 |
| B | 曜日（読みません） |
| C | 費目 |
| D | 収入 |
| E | 信用支出（カード等） |
| F | 現金支出 |
| G | 内容・摘要 |
| H | 区分（「法人」または「個人」・任意） |

**H列を入れておくと、判断の手間が大きく減ります。** 入力のときなら何を買ったか覚えているので、決算のときに思い出すより正確です。空欄でも動きます。

日付は書式を問いません。セルの中の値を直接読むので、表示が和暦でも米国式でも構いません。A列が日付でない行は、見出し・空行として自動で飛ばします。見出し行がなくてもかまいません。

読み込むのは各シートの先頭5000行・A〜H列までです。書式が最終行まで広がっているシートがあっても支障ありません。

## 使い方

1. ブラウザで開く（ファイルをダブルクリックしても、公開URLからでも）
2. 「0　会社の設定」に会社名・会計期間・前期の期末残高を入れる
3. Excelを放り込む
4. 画面の順に進む
